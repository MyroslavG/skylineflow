# Skyline Flow Toronto Plumbing

A modern one-page landing page for Skyline Flow Toronto Plumbing.

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy On Vercel

1. Push this repository to GitHub.
2. Import the repository in Vercel.
3. Keep the defaults:
   - Framework preset: Next.js
   - Build command: `npm run build`
   - Install command: `npm install`
4. No environment variables are required for this one-page site.

This project uses Next.js and requires Node.js `>=22.13.0`.
